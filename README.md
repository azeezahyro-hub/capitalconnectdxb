## Free hosting recommendation
Use GitHub Pages. Create a free GitHub account, create a public repository called:
`capitalconnectdxb`

Upload all files in this folder. Then:
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.

After GitHub gives you a temporary `username.github.io/...` URL, add your custom domain:
`capitalconnectdxb.com`

Then update your GoDaddy DNS as described in the accompanying chat instructions.

## Editing listings
In `index.html`, search for:
`Featured properties`

Replace the three sample cards with your live listings.

## Important
This version is a static site, so hosting can be completely free. The WhatsApp, phone and email buttons work without any paid backend.
